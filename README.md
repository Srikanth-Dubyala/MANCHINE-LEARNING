# MANCHINE-LEARNING
RAINFALL PREDICTION using Machine Learning
##  Project Overview
This project focuses on predicting rainfall using different machine learning models. The notebook includes data preprocessing, exploratory data analysis (EDA), feature engineering, and model training/evaluation.  
## Dataset
- The dataset contains weather-related features such as:
  - Temperature
  - Humidity
  - Pressure
  - Wind Speed
  - Rainfall (Target Variable)
  ##  Model Used
RandomForestClassifier
##  Results
- Random Forest Accuracy: 0.7446808510638298
- Mean cross-validation score : 0.8240398293029874
